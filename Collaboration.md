# Collaboration.md

Status: draft

This project is solo-owned and maintained by dwurdy (Vlad Durdeu). It is
intended to become public alongside the HeapHammer mod, so this document
exists to set small, honest expectations for outside users — it is not a
team-governance document, because there is no team.

## Ownership

- dwurdy has sole authority over the pack's mod list, version targets, and
  release decisions (see Decision.md).
- No other contributors are active. This may change; if it does, this
  document should grow to cover review/merge authority at that time —
  not before.

## Support

- Best-effort only. No SLA. Issues can be filed against this repo once it's
  public; response time depends on the maintainer's availability alongside
  HeapHammer and other projects.

## Contribution

- Not actively soliciting contributions at this stage (pre-v0.1.0). Once
  published, third-party mod-swap suggestions or version-target requests are
  welcome as issues, not unsolicited pull requests to `pack.toml` — the
  optimizer set was deliberately curated (Decision.md D-003) and changes to
  it need the same reasoning applied, not just "add mod X."

## Relationship to HeapHammer

- This pack is a separate repository from HeapHammer
  (`E:\Github2\HeapHammer`) and can version/release independently, but is
  developed by the same maintainer and intended to be discovered together.
